# Mikhuy

Landing page interactiva para Mikhuy, una startup cusquena de pedidos de comida local.

## Uso

Abre `index.html` directamente en el navegador. No requiere instalacion ni servidor.

La pagina presenta una experiencia tipo marketplace con una identidad visual editorial: hero de alto contraste, acentos lima y coral, catalogo con fotografias reales de platos peruanos y diseño responsive para escritorio y movil.

Incluye busqueda por plato o negocio, filtros por categoria, ordenamiento, favoritos filtrables, menu por restaurante, carrito lateral con cantidades y totales, confirmacion simulada de pedido y formulario funcional para registrar negocios aliados.

## Archivos

- `index.html`: estructura y contenido de la landing page.
- `styles.css`: sistema visual, composicion responsive, tarjetas, modales y animaciones.
- `script.js`: catalogo, filtros, favoritos, carrito y flujo de confirmacion.

## Ejecutar

Abre `index.html` directamente en el navegador. Las fotografias del catalogo se cargan desde Wikimedia Commons, por lo que se necesita conexion a internet para verlas.
